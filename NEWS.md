# hanwoo 0.1.0

## Initial CRAN submission

### Features

* `req_steer()`: Calculate nutrient requirements for Hanwoo steers based on body weight and daily gain.
* `req_bull()`: Calculate nutrient requirements for Hanwoo bulls based on body weight and daily gain.
* `hanwoo_info()`: Retrieve basic and carcass quality information from public data API.
* `hanwoo_price()`: Get Hanwoo auction price data from public data API.
* `hanwoo_bull()`: Retrieve KPN (Korean Proven Bull) information.
* `hanwoo_qrcode()`: Generate QR code for cattle identification.
* `hanwoo_stock()`: Get Hanwoo stock and price data.

### Included datasets

* `hanwoo1`, `hanwoo2`: Sample Hanwoo data.
* `hanwoo_kpn`: KPN bull information dataset.
* `hanwoo_farm`: Farm-level data.
* `Kcalendar`: Korean calendar data.
* `steer_c`, `steer_h`, `steer_m`, `steer_mhlc`: Prediction models for steer body weight.
* `weight_ku1`, `weight_ku2`: Weight data from Korea University.
* `program_nias`: NIAS program data.
